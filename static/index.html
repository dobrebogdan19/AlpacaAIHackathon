Self-auditing trading agent

This agent writes candidate trading strategies, backtests each one on historical daily bars, and promotes only those that clear a fixed gate — total return, max drawdown, trade count. Everything it rejects keeps running as a shadow portfolio, tracked forward on data the gate never saw.

When a rejected shadow consistently beats a strategy the gate promoted, the agent retires the promoted one and writes a post-mortem. The rejections matter as much as the promotions: they are the control group. Without tracking what it turned down, the agent has no way to tell whether its gate is doing anything at all. Paper trading only.
