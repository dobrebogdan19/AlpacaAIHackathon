Self-auditing trading agent

The agent writes trading strategies, backtests them on daily bars, and runs only the ones that clear a fixed gate. Everything it rejects keeps trading as a shadow portfolio, so there is a control group to judge the gate against. When a shadow beats a live strategy, the agent retires the live one. Paper trading only.

Decision log

Every candidate, with the gate's verdict and its reason — the record the agent judges itself on, most recent run first.
This instance runs on Render's free tier, which has no persistent disk: the database lives in /tmp and is wiped on every restart. Run and decision history therefore resets on restart and only covers the time since the instance last started. Positions and orders do not reset — on startup they are read back from the Alpaca account itself and any position whose originating run was lost is shown as reconstructed (D58).
