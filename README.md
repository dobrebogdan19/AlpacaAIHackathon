# DB history snapshots

Auto-generated by `.github/workflows/db-snapshot.yml`. One gzipped copy of
the live instance's SQLite database, refreshed about every 30 minutes,
because the Render free tier wipes the database on every restart
(DECISIONS.md D58 / D59).

`api._restore_from_snapshot()` loads `trading.db.gz` on boot **only when
the app's own database is empty**, so a snapshot never overwrites newer
live data. This branch is force-pushed to a single commit each run — do
not merge it.
